# DSA With C++

This repository contains beginner-to-intermediate C++ programs focused on Data Structures and Algorithms (DSA) practice and core C++ concepts.

## Project Overview

The repository is organized into:

- [Basics](Basics): fundamental C++ programs covering syntax, operators, variables, type conversion, and arithmetic logic.
- [Task](Task): assignment/task files for exercises and practice problems.
- Root files: standalone C++ programs and practice files.

## Topics Covered

- Variables and data types
- Arithmetic and logical operators
- Type casting
- Input/output basics
- Control flow and problem-solving exercises
- DSA practice files and task-based coding challenges

## How to Run

Compile a C++ file using:

```bash
g++ filename.cpp -o filename
./filename
```

Example:

```bash
g++ Basics/HelloWorld.cpp -o hello
./hello
```

## Notes

- Compiled binaries such as `.exe` files are ignored by Git via [.gitignore](.gitignore).
- Temporary files created by the editor or runner are also excluded from Git tracking.
- This repo is meant for learning and practicing C++ and DSA concepts step by step.
